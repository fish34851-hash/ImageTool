# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting feature in the Security tab of this repository. Include the affected browser, steps to reproduce, potential impact, and any suggested fix.

We aim to acknowledge a complete report within seven days. Confirmed fixes will be documented in the changelog and released as soon as practical.

## Privacy boundary

ImageTool performs image processing in the browser and does not upload selected files. The project does not include analytics, advertising, external scripts, or remote fonts.
