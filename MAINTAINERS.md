# Maintainers

## Primary maintainer

- [fish34851-hash](https://github.com/fish34851-hash)

The primary maintainer is responsible for issue triage, pull-request review, release decisions, security coordination, and keeping project documentation current.

## Becoming a maintainer

ImageTool is currently maintained by one person. Future maintainers should demonstrate sustained, constructive participation through issues, reviews, documentation, or code contributions.

Maintainer access is granted gradually and must not be exchanged for payment, stars, follows, or other artificial engagement.

## Decision making

Small changes are decided through pull-request review. Larger product or privacy changes should begin with a public issue so users and contributors can discuss the tradeoffs before implementation.
