# Five-minute user test

Real feedback helps ImageTool prioritize useful work. Please use a non-private sample image for this test and do not upload personal images to GitHub.

## Tasks

1. Open the [live application](https://fish34851-hash.github.io/ImageTool/).
2. Select one or more PNG, JPG, or WebP images.
3. Choose an output format and convert the images.
4. Try resizing or rotating an image and check the downloaded result.
5. If your browser offers installation, install the app and confirm that it opens after disconnecting from the network.

## Report your experience

Open the [feedback form](https://github.com/fish34851-hash/ImageTool/issues/new/choose) and include:

- The device and browser you used
- The task you attempted
- What you expected and what happened
- Whether you would use ImageTool again, and why

Screenshots are welcome only when they contain no private image content or personal information.

## Maintainer response

Maintainers will acknowledge actionable reports, reproduce bugs when possible, label the issue, and reference the fix or roadmap decision before closing it.
