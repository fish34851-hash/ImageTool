# ImageTool Roadmap

This roadmap describes intended directions, not guaranteed deadlines. Priorities may change in response to real user feedback and contributor interest.

## Released

### v0.1 — Local conversion

- PNG, JPG, and WebP conversion
- Quality controls and image preview
- Privacy-first, zero-dependency browser architecture

## In progress

### v0.2 — Batch workflow and maintainability

- Batch conversion for up to 20 images
- Proportional resizing
- Automated tests and pull-request checks
- Security, contribution, and community documentation

## Planned

### v0.3 — Offline installation

- Progressive Web App manifest
- Offline app shell
- Clear update behavior and cache controls
- Browser-level offline tests

### v0.4 — Editing and access

- Rotation and cropping
- Additional interface languages
- Keyboard and screen-reader review
- More output-size controls

## Community milestones

The project will prioritize genuine evidence of usefulness over artificial activity:

- Collect actionable feedback from real users
- Triage and label reported issues consistently
- Welcome and review external pull requests
- Publish release notes for every user-facing version
- Document real adoption signals without trackers or fabricated metrics
