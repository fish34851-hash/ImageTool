# Contributing to ImageTool

Thank you for helping improve ImageTool.

## Before you start

1. Search existing issues to avoid duplicates.
2. For a new feature, open an issue and describe the problem you want to solve.
3. Keep pull requests focused on one change.

## Development

```bash
npm run dev
```

Before submitting a pull request, confirm that the JavaScript syntax check succeeds:

```bash
npm run check
```

## Pull requests

- Explain what changed and why.
- Include screenshots for visual changes.
- Test with at least one PNG, JPG, or WebP file when changing conversion behavior.
- Use clear, respectful language.
